01 / El proyecto

Una forma más clara de entender la señal.

WiFiMap es un proyecto de simulación web para estimar y visualizar cómo se distribuye la cobertura WiFi dentro de un espacio. Busca mostrar de forma sencilla cómo influyen las dimensiones, la ubicación del router, los obstáculos y la frecuencia.

La página principal presenta el proyecto; el simulador es una herramienta independiente donde puedes configurar un escenario y explorar el resultado.

El simulador es un prototipo en desarrollo. Sus estimaciones son educativas y no sustituyen una medición real en el lugar.

03 / Bandas WiFi

Dos frecuencias, distintas características.

2.4 GHz

Mayor alcance potencial

Suele cubrir distancias mayores y puede atravesar algunos obstáculos con menos atenuación; también puede estar más congestionada.

5 GHz

Más capacidad a corta distancia

Puede ofrecer mayor velocidad y menos congestión, aunque la señal suele atenuarse más con la distancia y las paredes.

04 / Alcance actual

Un prototipo para explorar, no una medición profesional.

El motor usa una estimación de pérdida en espacio libre y atenuación orientativa por obstáculos. No modela reflexión, difracción, multipath ni interferencia ambiental, y sus valores aún no están validados experimentalmente. La web pública es la presentación del proyecto; para calcular resultados se necesita la API local.
